🎨 CSS

CSS es el lenguaje de estilos que define apariencia y diseño en la web. Permite transformar HTML en interfaces atractivas y responsivas.

Ruta de aprendizaje

  1. Fundamentos: Selectores, cajas, modelo de caja (box model), posicionamiento.
  2. Layout moderno: Flexbox y Grid para diseñar layouts responsivos.
  3. Preprocesadores y herramientas: SASS/SCSS, PostCSS, uso de variables y modularización.
  4. Responsive y accesibilidad: Media queries, diseño móvil primero y contraste de colores.
  5. Proyectos: Maquetar una landing page, crear temas y componentes reutilizables.
