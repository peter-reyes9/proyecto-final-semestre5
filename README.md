# 💻 Proyecto: Guía Básica para Iniciarse en la Programación

Este proyecto es una página web informativa creada con **HTML, CSS y JavaScript**, donde se presentan conceptos esenciales sobre programación, herramientas, rutas de aprendizaje y recursos gratuitos para principiantes.

---

## 📖 Contenido del sitio

### 🧠 Introducción a la Programación
Secciones breves donde se explica qué es la programación, por qué es importante y qué cualidades debe tener una persona que quiera dedicarse a ella.

### ⚙️ Extensiones de Visual Studio Code
Una lista con algunas extensiones útiles para programar mejor, con una descripción clara de su función y cómo ayudan al desarrollador.

### 🧩 Lenguajes de Programación
Una recopilación de los **10 lenguajes más usados**, con una mini guía sobre por dónde comenzar y enlaces a cursos gratuitos para aprenderlos.

### 🛠️ Rutas de Aprendizaje
Rutas sugeridas según el tipo de desarrollador que quieras ser:
- **Frontend Developer**
- **Backend Developer**
- **Fullstack Developer**

### 👤 Acerca de mí
Una breve presentación personal del autor del proyecto, compartiendo su interés por la programación y el aprendizaje constante.

---

## 🎯 Objetivo
Facilitar el inicio de las personas que quieren aprender programación, mostrando información clara, visual y organizada que sirva como punto de partida para su formación técnica.

---

## 🚀 Tecnologías utilizadas
- HTML5  
- CSS3
